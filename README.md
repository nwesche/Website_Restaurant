# Baan Siam – Thai-Restaurant mit Online-Bestellung

Konzept-Website (Mobile, Tablet, Desktop).

**Web-Vorschau:** https://nwesche.github.io/Website_Restaurant/ – reine Ansicht; Bestellungen, Zahlung und Dashboard funktionieren nur mit dem lokalen Server.

## Lokal starten (voller Funktionsumfang)

Voraussetzung: Python 3. Doppelklick auf `start_server.bat` oder:

```
python server.py
```

Dann http://localhost:8000/ öffnen. Einstellungen (PIN, Stripe, E-Mail) in `config.json`.
